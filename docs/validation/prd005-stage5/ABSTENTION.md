# 无答案优化实验 v1：不启用单一 COSINE 阈值

2026-09-08。本轮结论：实验执行完成，候选策略未通过质量护栏，生产检索默认行为未修改。

## 冻结与方法

沿用已授权 Go 四文件语料和63条Flash1024维向量，仅向已有Flash服务发送48条查询。原24条作为开发集；运行前生成24条不同表达的查询留出集（12有答案、12无答案，含相邻技术但不存在的功能）。留出manifest SHA256为 `25bbd31ab800283d9f8a5b17515d9a7c8f0b640eeb009fadce7f8518c1fd24de`。这不是不同仓库或不同文件的留出，标签仍待用户review，无答案仅指选定四文件。

先收集开发集原始向量候选分数与keyword候选，选择阈值并写入calibration.json，然后才执行留出查询。不根据留出结果重新调阈值。候选规则：最高COSINE低于阈值则返回精确symbol/path命中；否则保持原hybrid前5条。RRF分数不参与置信判断。

开发校准规则固定为：Recall/MRR最多下降5个百分点，有答案误拒绝≤5%，在可行阈值中选择最低无答案误命中率，同分选最低阈值。该开发约束比项目要求的5%相对退化护栏宽松，最终验收另外检查严格护栏，不混用两种口径。
