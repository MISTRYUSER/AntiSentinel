# PRD-005A Code Map Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有 Memory/Session 数据的前提下，建立绑定固定 Git Commit 的多语言代码地图（首批 Python、Go、TypeScript），支持定时异步构建、原子发布、精确符号/关系查询、源码 Evidence 回读及 Loop 接入。

**Architecture:** 采用方案 A：SQLite 作为登记、任务、租约、地图和发布代次的事实源；同机独立 code-map 服务包含调度器和单 Worker，Git 缓存使用 OS 文件锁，解析器运行在可终止子进程。首期先完成全量正确性，5A.4 再复用未变文件 AST 事实并重新计算关系；查询只读取已发布代次。

**Tech Stack:** Python 3.11+、SQLite WAL、Git CLI（固定 argv）、Tree-sitter（Python/Go/TypeScript）解析适配器、OpenTelemetry、现有 ToolRegistry/ToolExecutor、pytest、临时本地 Git fixture。

**Scope amendment:** Python-only 已废止；5A.2 前必须加入 Go 与 TypeScript 真实 Case，解析器统一走适配器接口；SCIP/Sourcegraph 与全文/向量索引另行评审。

**Spec:** `docs/superpowers/specs/2026-09-07-prd005a-code-map-design.md`

**Review revision (2026-09-07):** Added the A1/A2/A3 prerequisite task and real OTel parent restoration; created the staged runner in 5A.1 and extended it per stage; added the deployable daemon/config/compose assembly; moved lexical `contains` generation into 5A.2; corrected Case output commands to create a parent directory and pass a new child path; recorded the 005A/005 boundary for Sourcegraph/SCIP, full-text, and vector capabilities.

## Global Constraints

- 所有任务默认墙钟预算 120 秒；单 Case 最多初次执行加 2 次重试；同输入连续失败 2 次时停止扩展并定位根因。
- 任务总数和 Worker 并发由 SQLite 原子状态保证；全局 Worker 并发首期为 1，单仓库并发首期为 1。
- Git 单次操作超时 60 秒；从 Worker 领取起的构建超时 120 秒；心跳 10 秒、租约 60 秒；瞬时失败重试等待 30 秒、120 秒。
- 首次检查立即执行；成功后检查间隔为 1800、3600、7200、14400、14400 秒；发现新 SHA 重置为 1800 秒。
- 输入预算为 10000 个文件、单文件 1 MiB、总文本 64 MiB；单次源码返回最多 16 KiB；Context 最多 4 个片段、总量 32 KiB。
- 所有任务、快照、节点、边、Chunk、Evidence 和查询必须带 repository/snapshot/commit 作用域；禁止查询隐式构建或回退到最新分支。
- 不 checkout、不执行被分析源码、hooks、filter、submodule 或 LFS；不跟随仓库外符号链接；凭证只保存 `credential_ref`，日志脱敏。
- 行号为 1-based 且起止包含；源码 hash 基于实际保存的原始字节；AST UTF-8 列偏移不能直接当原始编码字节偏移。
- 只有经过 SQLite 重开读回且 Trace flush 完成，真实 Case 才能 `case_pass=true`；后台未捕获异常、错误 ready、跨范围引用必须为 0。
- 现有 Memory/Session 表和内容不得删除或改写；新增 schema 只能通过有序迁移引入。
- 设计中的默认值是可配置行为，不是性能承诺；首次性能运行只建立 5 次中位基线，后续同条件不得劣化超过 5%。
- 本计划的范围决策：005A 只交付绑定 Commit 的事实地图、精确查询、源码 Evidence 和 Loop 接缝；Sourcegraph/SCIP 关联、全文检索库（包括 FTS5/BM25 评测）和向量库/Embedding 属于后续 PRD-005，不能在 005A 任务中隐式加入。
- PRD-005 只能消费 005A 的 `MapSnapshot`、`CodeMapQuery` 和 `SourceEvidenceService` 接口；若要把 Sourcegraph/SCIP、全文库或向量库提前纳入 005A，必须先更新 PRD、设计文档、Case 和本计划，再开始实现。
